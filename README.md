## 这个脚本可以做什么？

- **处理地区限制**：提供免代理直连、选服和自定义 IP 等选项，用于辅助处理 Xbox Cloud Gaming 地区限制。
- **查看串流状态**：显示帧率、延迟、码率和分辨率等信息。
- **调整画面与编解码**：提供 720P／1080P、浏览器编解码偏好、画面比例，以及亮度、对比度、饱和度和清晰度调整。
- **改善操作体验**：提供自动全屏、触控控制显示与屏蔽等选项。
- **提供高级设置**：包含游戏语言、IPv6 优先、网络检测和实体服务器相关选项。

实际可用功能会因账号权限、服务区域、浏览器、设备和网络环境而不同，请以游戏页面中的设置面板为准。

## 快速开始

### 1. 安装用户脚本管理器

支持以下工具：

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)

### 2. 安装脚本

点击 [**立即安装最新版**](https://raw.githubusercontent.com/darkchaox/xbox-cloud-gaming-optimizer/main/Xbox-Cloud-Gaming-Optimizer.user.js)，并在脚本管理器中确认安装。

### 3. 打开 Xbox Cloud Gaming

访问：

- `https://www.xbox.com/play`
- `https://play.xbox.com/`

进入游戏后打开脚本设置面板，建议先使用默认设置确认功能正常，再调整选项。

## 使用建议

1. 修改设置时一次只调整一个选项。
2. 出现异常时恢复最近修改的配置并刷新页面。
3. 更新脚本前记录重要自定义配置。
